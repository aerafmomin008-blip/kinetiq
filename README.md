# KinetIQ

KinetIQ is an AI-powered mobile application for meal analysis and nutrition insights. It combines a Flutter mobile interface with a Python backend to provide meal details and nutritional information.

## Features

- AI-powered meal analysis
- Displays identified meal information
- Provides calorie, protein, and carbohydrate insights
- Flutter-based cross-platform mobile interface
- Python backend for analysis logic

## Tech Stack

- Flutter
- Dart
- Python
- AI and nutrition analysis

## Getting Started

1. Clone the repository:

    git clone https://github.com/aerafmomin008-blip/kinetiq.git
    cd kinetiq

2. Install Flutter dependencies:

    flutter pub get

3. Run the application:

    flutter run

## Security Note

Keep the backend `.env` file local. Do not upload API keys or secrets to GitHub.
